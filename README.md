National Cyber League (NCL) reverse engineering and exploitation lab focused on analyzing compiled Python bytecode. Used Kali Linux, Python, uncompyle6, and Vim to decompile a .pyc file, troubleshoot decompiled source code, analyze password-validation logic, and identify character, ASCII, and length constraints. Applied static analysis, debugging, and constraint-based problem solving to derive and validate an input that satisfied the program's authentication conditions.
